# Butterfly for Mac

**A scrolling tiling window manager for macOS.** Every window sits side by side on one horizontal strip
that scrolls past the edge of your screen. Nothing hides behind the browser and nothing shrinks:
swipe, scroll or use the keyboard to reach the window you need.

[![Butterfly for Mac](https://butterflyformac.com/og.png)](https://butterflyformac.com/)

This repository holds the signed and notarized builds and the update feed. The app's website is
**[butterflyformac.com](https://butterflyformac.com/)**.

## Download

- [Download the latest Butterfly.dmg](https://github.com/butterflyformac/releases/releases/latest/download/Butterfly.dmg)
- Or with Homebrew: `brew install --cask butterflyformac/tap/butterfly` (details in [homebrew-tap](https://github.com/butterflyformac/homebrew-tap))

Free for 7 days, no card, no account. Then a one-time payment.
macOS 14 Sonoma or later, Apple silicon and Intel. Butterfly updates itself.

## What it does

- Every window side by side on one strip that scrolls, so windows keep their size
- Three-finger swipe, mouse thumb wheel and keyboard control
- Overview of every window and up to nine workspaces
- Stacks and tabs
- A strip on every display
- Meeting Privacy: blurs private windows while you share your screen
- Every shortcut can be changed

Inspired by [PaperWM](https://github.com/paperwm/PaperWM) and [niri](https://github.com/YaLTeR/niri) on Linux.
